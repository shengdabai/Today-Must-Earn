# 今天也得赚钱 💸

> 你不是不想成功,你只是每天都不想开始工作。
> 这个 App 不管理待办、不讲大道理,只用黑色幽默、反讽、整活,把你从摸鱼里薅回工位。

一个 **Electron + React + TypeScript** 的 macOS 桌面应用,极简大字报风格,贴吧老哥的嘴,评论区神回复的灵魂。

## 核心功能

| 功能 | 说明 |
|---|---|
| 💰 实时赚钱进度 | 全屏大字报 / 悬浮窗两种模式,按月薪折算每分钟、每秒收入,实时跳动 |
| 📅 接入 Apple 日历 | 自动数今天日历里的「中文课」,一节 = 20€(可改),并入今日已赚 |
| 🐟 摸鱼检测 | 长时间无操作(发呆/离开)、切到娱乐网站/App、疯狂切屏「假装很忙」三类摸鱼实时识别 |
| 🔥 AI 吐槽 | 摸鱼被抓现行,立刻弹毒舌吐槽。本地语料库零 key,可选接外部 AI |
| 📨 未来的自己 | 3 年后 / 退休的你 / 破产的你… 随机发消息催你干活,从恳求到威胁 |
| 📊 财富进度条 | 车 / 房 / 旅游等梦想目标,实时显示「今天赚的够梦想的百分之几」 |
| 🔮 人生模拟器 | 并排推演「继续摸鱼」vs「继续努力」两条人生岔路,努力线结局随专注时长升级 |
| 🏆 成就 / 称号 | 每专注一段时间解锁搞笑称号和奖励(番茄刺客 / 卷王本王 / 碳基永动机…) |
| 🖼️ 梗图墙 | 赛博毒鸡汤 + 评论区神回复轮播 |

## 跑起来

```bash
npm install
npm run dev          # 开发模式(热重载)
npm run typecheck    # 类型检查
npm run dist:mac     # 打包成 macOS .dmg
```

首次运行需在 **系统设置 → 隐私与安全性** 授予:
- **日历**:读取「中文课」节数(否则课程收入为 0)
- **屏幕录制**:检测当前在哪个 App/网页摸鱼(否则只能靠「发呆检测」)

> 没授权也能用,只是摸鱼检测会降级到「无操作发呆」这一种。

## 两种显示模式

- **悬浮窗**:常驻右上角,半透明、置顶、不抢任务栏,瞄一眼就知道今天赚了多少 + 最新吐槽
- **全屏大字报**:巨大的数字、财富进度、人生模拟器、梗图墙铺满整屏,适合「该干活了」的仪式感时刻

从 **菜单栏托盘图标** 切换模式、暂停/开始计时、退出。

## 配置

点 ⚙️ 设置:月薪、币种、每月工作天数/时长、日历课程关键词与单价、摸鱼判定秒数、梦想目标。
配置用 `electron-store` 本地持久化,专注时长跨天自动归零。

## 可选:接入真·AI 吐槽

默认用内置语料库(零依赖、离线可用)。想让吐槽更刁钻,设环境变量走 OpenAI 兼容接口:

```bash
export MONEY_AI_ENDPOINT="https://api.xxx.com/v1/chat/completions"
export MONEY_AI_KEY="你的key"      # 只读环境变量,绝不写进仓库
export MONEY_AI_MODEL="gpt-4o-mini"
```

调用失败一律自动降级回本地语料,绝不阻塞。

### 隐私说明:开启外部 AI 后会发送什么

- **默认完全离线**:不设 `MONEY_AI_ENDPOINT` 和 `MONEY_AI_KEY`(两个都要设,缺一个就不联网),应用不会向任何外部地址发送吐槽相关数据。
- **何时发送**:只有两个变量都设置、且当前判定为非专注状态(发呆 / 娱乐 / 疯狂切屏)触发吐槽时才请求;同一状态最多每 20 秒一次,状态变化时立即一次。专注状态不发送。
- **发送内容**:发往你配置的 `MONEY_AI_ENDPOINT`,带你的 `MONEY_AI_KEY`,内容是一段提示词,包含:当前状态(idle / entertainment / switching)、当前前台应用名称(如「微信」,发呆时同样会带上)、已发呆或摸鱼的分钟数、折算出的每分钟收入(由月薪推算,等于间接透露月薪量级)、近期切屏次数,以及模型名。
- **不发送**:窗口标题、网址、屏幕内容、日历内容、月薪原值、你的姓名等其他数据。
- 请求超时 8 秒,失败即回退本地语料。配置的服务商会看到这些内容,请只填你信任的接口。

## 架构

```
electron/         主进程
  main.ts         窗口/托盘/IPC/每秒核心循环
  monitor.ts      摸鱼检测(idle + active-win + 切屏频率)
  calendar.ts     Apple 日历 osascript 读课
  earnings.ts     月薪→每分钟/秒 + 课程收入合并
  roast.ts        吐槽生成(本地 + 可选 AI 钩子)
  store.ts        配置/专注时长持久化(跨天重置)
  preload.ts      contextBridge 安全桥
src/              渲染层(React)
  components/      MoneyCounter / RoastBanner / FutureSelf / WealthProgress
                  / LifeSimulator / Achievements / MemeWall / Settings
  data/           roasts / future-self / achievements / memes 语料库
  hooks/          useAppState(订阅主进程快照与事件)
  lib/            types / format
```
